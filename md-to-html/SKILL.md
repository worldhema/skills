# /md-to-html

将 Markdown 转为**自包含单文件 HTML**（内联 CSS/JS，可直接打开、发送、打印，无外部依赖）。带左侧目录、滚动高亮当前章节；提供 `--backup` 时自动 diff 高亮本次新增内容，成为逐章审阅稿。

## 何时使用

- 用户要把 `.md` 文件变成能在浏览器里看的 HTML 页面
- 用户要"带目录的 HTML""网页版""方便阅读的 html"
- 用户在修订文档后要一份**审阅稿**——把"修订前"和"修订后"的差异高亮出来逐章核对（这是本书稿修订工作流的核心）

## 快速命令

```bash
# 普通模式：干净的带目录阅读页
python3 ~/.claude/skills/md-to-html/scripts/md_to_html.py 输入.md

# 审阅模式：diff 高亮本次新增（-b 给修订前版本）
python3 ~/.claude/skills/md-to-html/scripts/md_to_html.py 输入.md -b 修订前.md

# 指定输出与标题
python3 ~/.claude/skills/md-to-html/scripts/md_to_html.py 输入.md -o 审阅稿.html -t "《书名》审阅稿"
```

## 参数

| 参数 | 说明 |
|------|------|
| `输入.md` | 输入 Markdown 文件（必填，须存在） |
| `-b, --backup` | 修订前版本 `.md`；提供后进入审阅模式，diff 高亮本次新增 |
| `-o, --output` | 输出路径，默认与输入同名 `.html`（同一目录） |
| `-t, --title` | 页面标题，默认取文件名 |
| `--lang` | 页面语言，默认 `zh-CN` |
| `--no-banner` | 不显示顶部信息条 |
| `-q, --quiet` | 静默，不打印统计 |

## 输出说明（审阅模式高亮图例）

- 🟩 **绿色块**（左边框）= 新增整段/整节；新增标题带"新增"角标，目录中带红色"新"角标
- 🟨 **黄色标记** = 句中新增内容
- ⬜ **浅灰标记** = 纯标点改动（如逗号→顿号），**默认隐藏**，可勾选"标点改动"开关查看
- 顶部两个开关：**高亮新增**（关闭即还原纯净全文）、**标点改动**
- 顶部统计条显示新增段落/标题数与新增字符数

## 支持的 Markdown 语法

脚本内建常见 Markdown 解析（块级 + 行内），转换时无需任何配置：

| 语法 | 渲染 |
|------|------|
| `#`~`####` 标题 | `h1`~`h4`，最高级作页眉不进目录 |
| **标准 Markdown 表格**（含 `|---|---|` 分隔行） | 真 `<table>`：表头 `<th>`、隔行变色、横向滚动 |
| 纯 ASCII 手绘表格（`+---+` / 无分隔行的 `\|` 块） | 等宽 `<pre>` 保留，宽表格横向滚动 |
| **`**加粗**`** / `` `代码` `` | `<strong>` / `<code>`，自动应用于段落、标题、表格单元格、列表项、引用内 |
| `> 引用` | `<blockquote>`（连续 `>` 行合并为一个引用块） |
| `---` / `***` | `<hr>` 水平分隔线 |
| `- `/`* `/`+ ` 无序列表、`1. ` 有序列表 | `<ul>` / `<ol>`，连续同类项合并为一级列表 |
| ```` ```lang ```` 围栏代码块 | `<pre class="codefence">` 等宽块，保留语言标记 |
| 框线架构图（`│`/`┌`/`├` 开头的连续块） | 等宽 `<pre>` 保留（无围栏时也能识别） |

## 处理要点（核心经验）

1. **标题层级映射**：`#`→h1、`##`→h2、`###`→h3、`####`→h4；最高一级标题（如书名）作页眉、**不进目录**，目录从二级标题起。
2. **目录结构**：按标题层级生成嵌套列表；滚动时高亮当前所在章节（scrollspy）；无标题时自动不渲染侧栏。
3. **表格**：标准 Markdown 表格（含分隔行）解析为真 `<table>`；纯 ASCII 手绘表格（`+---+` 开头、无分隔行）保留为等宽 `<pre>`。两者按"是否含 `|---|` 分隔行"自动区分，勿手动干预。
4. **行内格式**：`**加粗**`→`<strong>`、`` `代码` ``→`<code>`，经 `inline()` 应用于所有文本节点（段落/标题/表格单元格/列表项/引用）。审阅模式下行内 diff 高亮的行不做行内转换，避免标签冲突。
5. **块级顺序**：围栏代码块 → 标题 → 框线图 → 表格 → 引用 → 分隔线 → 列表 → 段落，按此优先级逐行扫描；`---` 独立行是分隔线，不会被误判为列表或表格。
6. **diff 原理**：先按行 diff（`difflib.SequenceMatcher`），整行新增→绿块；行内差异再做字符级 diff→黄标；纯标点差异单独灰标。`len(旧行)==len(新行)` 才做字符级，否则整行视为新增，避免误标。
7. **中文字体**：正文使用系统无衬线中文字体栈（PingFang/微软雅黑/Noto Sans CJK），等宽块用 SF Mono/Menlo/Consolas。
8. **自包含**：所有 CSS/JS 内联，无 CDN、无外部请求，可离线打开。
9. 输出目录若与输入不同，先确保目录存在。

## 与其它 skill 的分工

- 需求是"网页版/审阅稿"用本 skill；需求是"导出 PDF/电子书"用 `md2book`
