# 版本备份目录

> 本书的版本历史由 **git** 承载。本目录存放里程碑说明文档，以及常用命令备忘。
> 每章完成即 commit 一次，完整历史都在 `git log` 里，可随时回滚任意章节。

## 里程碑记录
每完成 5 章，在 `05-版本备份/` 下写一份里程碑说明，如 `第005章-里程碑.md`：
- 本阶段完成章节
- 剧情进展小结
- 已回收/新增伏笔
- 下一阶段规划

## git 常用命令

```bash
# 查看提交历史
git log --oneline

# 查看某个提交改了什么
git show <commit-hash>

# 回滚某章到上一个版本
git checkout <commit-hash> -- 02-正文存稿/第XXX章-标题.md

# 回滚整本书到某历史点（谨慎，会丢失之后改动）
git reset --hard <commit-hash>
```

## 提交约定
见 `04-技能配置/子技能7-自动版本备份.md`：章节 `feat(chapter): ...`、设定 `feat(setting): ...`、修正 `fix(chapter): ...`。
