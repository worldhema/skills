# 子技能7 · 自动版本备份

## 技能名称
自动版本备份

## 适用场景
每章创作的第 7 步；也用于设定变更、审查修正后的存档。

## 输入格式
- 本章全部改动（正文、细纲、设定文档、追踪文档）

## 输出格式
一次成功的 git commit。

## 执行步骤
1. `git status` 确认待提交改动
2. `git add -A`
3. `git commit -m "feat(chapter): 第XXX章-标题"`
4. `git log --oneline -5` 确认提交成功

## Commit Message 约定
| 场景 | message |
|------|---------|
| 完成一章 | `feat(chapter): 第XXX章-标题` |
| 设定/大纲变更 | `feat(setting): <描述>` |
| 审查修正 | `fix(chapter): 第XXX章 审查修正` |
| 成书/脚本/杂项 | `chore: <描述>` |

## 注意事项
- 提交前确认正文定稿、追踪文档已更新，避免重复提交半成品。
- 版本历史查看与回滚命令见 `05-版本备份/说明.md`。
