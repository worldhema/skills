# 主技能 · 平台小说章节全流程创作

## 技能名称
平台小说章节全流程创作

## 适用场景
每次创作一个新章节时调用；也可在「初始化新书」「审查修改」等大流程中作为调度入口。

## 输入格式
- 章节号（如「第 7 章」）
- 用户意图 / 创作方向（如有）

## 输出格式
- 定稿正文 → `02-正文存稿/第XXX章-标题.md`
- 章节细纲 → `01-大纲细纲/章节细纲/第XXX章-细纲.md`
- 更新后的设定与追踪文档 → `03-设定文档/`
- git commit → 完成一次 `feat(chapter): 第XXX章-标题`

## 执行步骤
按 7 步循环依序调度子技能：

1. 资料整理 → `novel-prep`
2. 剧情推演 → `novel-outline`
3. 正文生成 → `novel-write`
4. 合规审查 → `novel-review`
5. 内容打磨 → `novel-polish`
6. 故事线更新 → `novel-track`
7. 自动备份 → `novel-backup`

## 边界与调度原则
- 主技能**不直接生成正文**，只负责编排与质量控制。
- 每步输出是下一步输入；步骤 4 若不通过，步骤 5 必须处理全部问题后才能进入步骤 6。
- 创作前用户意图不明确时，先与用户讨论本章方向，再启动循环。

## 注意事项
- 章节号必须递增连续，正文命名三位数补零。
- 每章开始前重读 `03-设定文档/红线规则.md`、`人物设定.md`、`伏笔追踪.md`。
