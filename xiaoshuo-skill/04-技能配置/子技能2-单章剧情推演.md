# 子技能2 · 单章剧情推演

## 技能名称
单章剧情推演

## 适用场景
每章创作的第 2 步；在资料整理简报基础上规划本章情节。

## 输入格式
- 创作简报（novel-prep 输出）
- `01-大纲细纲/全书大纲.md`、`分卷细纲.md` 对应章节规划

## 输出格式
章节细纲，写入 `01-大纲细纲/章节细纲/第XXX章-细纲.md`：
- 本章 3~5 个核心事件（按序）
- 核心冲突与转折点
- 场景 / 地点 / 登场人物
- 章末钩子
- 涉及的新伏笔（预登记）

## 执行步骤
1. 确认本章在全书主线中的位置与任务
2. 设计事件序列（3~5 个），保证冲突递进、节奏起伏
3. 确定章末钩子（悬念 / 反转 / 情感落点）
4. 写入细纲文件

## 注意事项
- 细纲不偏离主线，不引入超出大纲规格的重大事件（重大事件须先与用户确认）。
- 事件数控制：单章约 2000 字，3~5 个事件最合适，过多则浅尝辄止。
