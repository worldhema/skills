# 自动化技能 · 每日存稿备份与合规扫描

## 技能名称
每日存稿备份与合规扫描

## 适用场景
定时/每日触发，或用户要求「扫描全文」「检查合规」时调用；作为主流程之外的兜底保障。

## 输入格式
- 无（自动触发）
- 参考 `03-设定文档/合规敏感词清单.md`

## 输出格式
扫描报告：
1. 合规扫描结果（命中敏感词/违规描写的章节、位置、命中词）
2. 备份状态（`git status` 未提交改动清单）
3. 处理建议

## 执行步骤
1. 读取 `合规敏感词清单.md`，整理关键词
2. 扫描 `02-正文存稿/` 全部正文，匹配敏感词，报告章节号/位置/命中词
3. 检查敏感描写风险段落（政治、色情、暴力、血腥）
4. `git status` 检查未提交改动，有则提示执行 `novel-backup`
5. 输出扫描报告

## 注意事项
- 只报告风险，不自动改写正文；是否处理由用户决定。
- 敏感词清单支持随时增补（发现新的违规词就加进去）。
- 检测到高风险内容时，建议联动 `novel-review` 做一次完整复审。
