# 子技能1 · 资料整理与前文梳理

## 技能名称
资料整理与前文梳理

## 适用场景
每章创作的第 1 步；也用于中途断更多日后恢复创作前的前情回顾。

## 输入格式
- 待创作章节号

## 输出格式
结构化创作简报（文本），固定四段：
1. 前文梗概（最近 2~3 章要点）
2. 人物当前状态清单
3. 未回收伏笔清单（ID / 埋设章节 / 计划回收章）
4. 本章衔接要点（上章结尾钩子）

## 执行步骤
1. 读取 `02-正文存稿/` 最近几章，提取剧情要点
2. 读取 `03-设定文档/人物设定.md`，摘取当前状态字段
3. 读取 `03-设定文档/伏笔追踪.md`，筛选「未回收」伏笔
4. 汇总输出简报

## 注意事项
- 只整理既有事实，不推断、不新增情节。
- 简报长度控制在能支撑本章创作即可，不冗长堆砌。
