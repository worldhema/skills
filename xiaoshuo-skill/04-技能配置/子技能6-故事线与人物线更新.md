# 子技能6 · 故事线与人物线更新

## 技能名称
故事线与人物线更新

## 适用场景
每章创作的第 6 步；正文定稿后同步所有追踪文档。

## 输入格式
- 本章定稿正文
- `03-设定文档/`：人物设定、伏笔追踪
- `01-大纲细纲/分卷细纲.md`

## 输出格式
更新后的：
1. `伏笔追踪.md`（新伏笔登记 / 旧伏笔标记回收）
2. `人物设定.md`（主要人物当前状态）
3. `时间线.md`（当前情节时间线追加本章时间锚点）
4. `分卷细纲.md`（进度标注：已写至第几章）
5. 本章梗概（追加至汇总索引）

## 执行步骤
1. 通读正文，提取剧情事实变化
2. 扫描新伏笔 → 伏笔追踪表新增行，分配伏笔ID（`F-001` 起递增）
3. 扫描被回收伏笔 → 状态改「已回收」，标注回收章节
4. 更新各人物当前状态字段
5. 更新 `时间线.md`：当前情节时间线追加本章一行（时间/关键事件/人物状态变化）；正文与时间线冲突时先修正再落盘
6. 更新分卷细纲进度与本章梗概

## 注意事项
- 只记录正文中已发生的事实，不推断未发生情节。
- 伏笔ID 全局唯一，回收后保留行（不删除），便于追溯。
- 时间锚定铁律：正文的日期/季节/年龄/称谓必须与 `时间线.md` 一致，本章事实如需修正历史时间线，一并同步。
