# 子技能4 · 合规与一致性审查

## 技能名称
合规与一致性审查

## 适用场景
每章创作的第 4 步；也用于全书里程碑审查、每日合规扫描的复核。

## 输入格式
- 本章正文文本（纯文本，无标题行）
- `03-设定文档/`：人物设定、红线规则、伏笔追踪、合规敏感词清单

## 输出格式
结构化审查报告：
- **结论**：合规 / 不通过
- **问题清单**（逐条）：类型（OOC / 剧情矛盾 / 违禁 / 伏笔冲突 / 红线违反 / 张力不足 / 结构问题）、原文位置、问题说明
- **修改建议**：每条问题的修改方向

## 执行步骤
1. 检查人物对话是否符合其性格设定
2. 检查本章剧情是否与前文矛盾
3. 检查平台规则合规性（违禁词 / 敏感描写）
4. 检查伏笔使用是否与追踪表一致（应回收的有没有回收，未回收的是否被误写）
5. 张力审查（对照 `创作方法论.md`）：本章冲突是否清晰（欲望+阻碍+代价）、冲突是否升级、情绪曲线是否成立
6. 结构审查：章末钩子是否有效、场景是否有转折、节奏是否张弛有度
7. 输出结构化审查报告

## 注意事项
- **不修改正文**，只输出审查意见；修改由「内容优化打磨」技能执行。
- 报告必须逐条给出可执行的修改建议，供打磨步骤直接消费。
- 张力与结构审查标准见 `04-技能配置/创作方法论.md`。
