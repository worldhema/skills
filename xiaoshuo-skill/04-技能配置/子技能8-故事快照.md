# 子技能8 · 故事快照

## 技能名称
故事快照（novel-snapshot）

## 适用场景
- 每章定稿后想整体确认「现在剧情写到哪、每个人物在哪做什么」
- 停更/断更多日后恢复创作前，快速重建全局状态
- 发现剧情疑似跑偏时，用快照对照大纲找出偏差
- 准备推进下一章前，确认待推进的剧情点

## 输入格式
- `02-正文存稿/` 最新章节（确定当前进度）
- `03-设定文档/人物设定.md`、`时间线.md`、`伏笔追踪.md`
- `01-大纲细纲/全书大纲.md`、`分卷细纲.md`

## 输出格式
`06-快照存档/第XXX章-故事快照.md`，内容结构如下：

```markdown
# 故事快照 · 第XXX章

## 一、全局状态
- 当前时间点：<!-- 来自时间线.md 当前情节时间线末行 -->
- 当前主要场景 / 地图位置：
- 当前主线阶段：<!-- 英雄之旅第几步 / 三幕第几幕 / 大纲第几阶段 -->

## 二、角色当前状态
| 角色 | 当前位置 | 时间点 | 正在做什么 | 当前目标 | 与上章变化 |
|------|---------|--------|-----------|---------|-----------|
| 主角 | | | | | |
| | | | | | |

## 三、进行中的剧情线
- 主线：<!-- 当前推进到什么 -->
- 支线：<!-- 各支线状态 -->
- 未解悬念：<!-- 正文中已抛出尚未解答的悬念 -->

## 四、当前最相关的未回收伏笔
| 伏笔ID | 内容 | 埋设章 | 计划回收章 | 当前状态 |
|--------|------|--------|-----------|---------|
| | | | | |

## 五、剧情进度对照（校正）
- 与全书大纲的偏差：<!-- 如实记录偏差；无偏差则写「无」 -->
- 发现的设定冲突：<!-- 角色/时间/伏笔与设定文档不一致处，提示修正 -->
- 待推进的剧情点（下一章候选）：<!-- 1~3 个可推进的方向 -->

## 六、时间线锚点摘要
<!-- 时间线.md 当前情节时间线最近 3 行 -->

## 七、与上一快照的变化
<!-- 对比 06-快照存档/ 上一份，列出角色位置/关系/剧情线的关键变化；首份快照写「首份」 -->
```

## 执行步骤
1. 读取 `02-正文存稿/`，确定最新章节号（如无存稿则报「第 0 章/初始化前」）
2. 读取 `人物设定.md`，摘取各角色「当前位置 / 当前状态 / 当前目标」字段
3. 读取 `时间线.md`，摘取当前情节时间线末行 + 时间规则要点
4. 读取 `伏笔追踪.md`，筛选「未回收」伏笔
5. 读取 `全书大纲.md` + `分卷细纲.md`，对照当前进度定位主线阶段
6. 对比 `06-快照存档/` 中上一份快照，生成变化摘要
7. 按上述模板聚合写入 `06-快照存档/第XXX章-故事快照.md`

## 注意事项
- **只记录正文已发生的事实**，人物「正在做什么」必须来自最新章节，不得替角色虚构下一步行动。
- 快照发现不一致（角色状态、时间、伏笔与设定文档矛盾）时，**如实提示**——这是快照的核心价值（校正剧情），宁可暴露问题也不粉饰。
- 快照保留历史版本不删除，用于跨章对比；最新快照即目录中章节号最大者。
- 快照是辅助工具，不属于单章 7 步循环；与 `novel-track`（每章维护人物/时间/伏笔）互补：track 负责把状态写回设定文档，快照负责把全局状态呈现在一个文件里供校正。
