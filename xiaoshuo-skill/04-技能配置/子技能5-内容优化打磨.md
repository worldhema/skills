# 子技能5 · 内容优化打磨

## 技能名称
内容优化打磨

## 适用场景
每章创作的第 5 步；审查发现问题后，或在用户反馈不满意时调用。

## 输入格式
- 本章正文初稿
- 审查报告（如有）
- `03-设定文档/写作风格.md`

## 输出格式
打磨后的定稿正文 → `02-正文存稿/第XXX章-标题.md`

## 执行步骤
1. 逐条处理审查报告问题（OOC 改回人设 / 矛盾修正 / 违禁删除改写 / 伏笔冲突调整）
2. 润色对话：更口语、有腔调、删书面腔
3. 增强画面感：补具体动作、环境细节、感官描写
4. 调整节奏：长短句穿插，冲突段落提速
5. 强化章末钩子：确保结尾有悬念或情绪落点
6. 通读定稿，确认无残留问题后落盘

## 注意事项
- 打磨不改变剧情事实与人物设定，只优化表达。
- 字数保持约 2000 字，不因打磨膨胀或缩水。
- 打磨后如改动较大，可再回 `novel-review` 复核一次。
