# 创作方法论

> 本文件是本书创作的"方法论知识库"，供 `novel-method`（灵感引擎）、`novel-outline`（剧情推演）、`novel-write`（正文生成）、`novel-review`（审查）共同参考。
> 覆盖：戏剧冲突、英雄之旅（千面英雄）、叙事结构、写作手法、人物弧光、场景设计、灵感生成法。

## 一、戏剧冲突

**冲突是故事的引擎。** 没有冲突就没有故事。创作每一章前先问：本章的冲突是什么？

### 五种经典冲突（人物与外界的对抗关系）

| 类型 | 本质 | 示例 |
|------|------|------|
| 人物 vs 人物 | 目标与利益的直接对抗 | 主角 vs 对手、主角 vs 主考官、同事抢功劳 |
| 人物 vs 自我 | 内心挣扎：欲望/恐惧/道德/旧我 | 想复仇却怕变成恶魔、想表白却自卑 |
| 人物 vs 社会 | 个人 vs 规则/偏见/体制 | 小人物对抗潜规则、不被理解的理想 |
| 人物 vs 自然/环境 | 生存与适应 | 荒野求生、天灾、资源匮乏 |
| 人物 vs 命运/超自然 | 宿命、神意、未知力量 | 命中注定的悲剧、不可名状的存在 |

### 冲突三要素：欲望 + 阻碍 + 代价

```
欲望（人物此刻想要什么）
  × 阻碍（谁/什么挡在中间）
  × 代价（得不到会失去什么 / stakes）
  = 冲突成立
```

**校验法**：一个冲突若把"代价"拿掉就不紧张，说明它不够硬。每章主冲突必须有明确的"失去什么"。

### 制造冲突的方法

- **目标错位**：两个人各怀目标，同一条路上相遇，必然相撞
- **立场对立**：都对，但立场互斥（警察与劫匪、公司与用户）
- **秘密**：人物隐藏的信息被他人窥探
- **误会产生**：信息不对称导致误解（注意：误会不会凭空消失，要设计揭穿时刻）
- **资源稀缺**：金钱/时间/权力/爱情只有一个，人多粥少
- **时间压力**：倒计时逼出决策（deadline 是免费的张力）
- **新旧规则碰撞**：新秩序冲击旧秩序

### 冲突升级阶梯（章节级）

每章冲突应在**升高**而非原地打转：
低度摩擦 → 明确对峙 → 激烈爆发 →（本章或数章后）阶段性解决 → 引出更大冲突。

**黄金法则**：解决一个冲突时，顺手埋下更大的一个。

## 二、英雄之旅（《千面英雄》/ Hero's Journey）

约瑟夫·坎贝尔（Joseph Campbell）在《千面英雄》中提出"单一神话"（Monomyth）：一切伟大故事的骨架都是**英雄离开日常世界 → 经历考验 → 归来并改变**。有 17 阶段与通用 12 步两种切分，创作时用 **12 步** 最顺手。

### 通用 12 步（三幕）

| 阶段 | 内容 | 功能 |
|------|------|------|
| ① 平凡世界 | 英雄的日常，缺陷与未满足的渴望 | 让读者认识主角、建立代入 |
| ② 冒险的召唤 | 打破平静的事件/邀请/威胁 | **激励事件**，故事开跑 |
| ③ 拒绝召唤 | 因恐惧/责任/不信而犹豫 | 展现人物软肋 |
| ④ 遇见导师 | 获得指引/装备/信念 | 提供信息与资源 |
| ⑤ 跨越第一道门槛 | 正式进入"非常世界"，无法回头 | 第一章收尾的强钩子 |
| ⑥ 考验、盟友与敌人 | 一连串小考验，交朋友树敌人 | 中段的主干，可多章展开 |
| ⑦ 接近最深的洞穴 | 逼近核心难题，最后的犹豫与准备 | 中点后的蓄力 |
| ⑧ 严峻考验 | 直面最大危机，最接近死亡/失败 | 全书最低谷/假死点 |
| ⑨ 获得奖赏 | 夺取成果，但尚未结束 | 暂时喘息 |
| ⑩ 返回的路 | 逃出生天，代价显现 | 收尾前的波折 |
| ⑪ 复活 | 最后一次、也是最彻底的考验，脱胎换骨 | **高潮** |
| ⑫ 带着灵药归来 | 回到世界，带回改变世界的"灵药"，成为新我 | **结局** |

### 章节映射对照表（全书设计用）

在 `01-大纲细纲/全书大纲.md` 中把"英雄之旅阶段 ↔ 章节范围"写成表，作为主线骨架：

```
| 英雄之旅阶段 | 对应章节 | 本章要完成的转换 |
|-------------|---------|----------------|
| ① 平凡世界   | 第001~002章 | 建立主角日常与缺陷 |
| ② 冒险的召唤 | 第003章      | 激励事件发生 |
| ...          | ...          | ...             |
```

### 灵感提问法（把 12 步变成提问模板）

创作卡壳时，用这些提问倒逼灵感：
- 主角的**平凡世界**缺什么？这个缺憾如何是后面所有冒险的源头？
- 是什么**召唤**他离开？（威胁？诱惑？邀请？责任？）
- 他**拒绝**召唤的借口是什么？这个借口如何反映他的内在缺陷？
- 谁是**导师**？他教会主角什么"教训"？（读者也会需要这堂课）
- **跨越门槛**时主角丢了什么、断了哪条后路？
- **严峻考验**里，主角失去/牺牲了什么才过关？（真正的成长必有牺牲）
- **灵药**是什么？主角归来后，世界因他改变了什么？

### 应用提醒

- 英雄之旅是**骨架**，不是配方。都市日常、温情向作品可弱化冒险色彩，但"考验—挫折—成长—回归"的**内在结构**仍普遍适用。
- 不要为了套用而写八个阶段；一本书可只突出其中 4~6 个节点，其余自然过渡。
- 对长篇连载：**每卷可做一次迷你英雄之旅**（小召唤→小考验→小回归），卷与卷层层升级。

## 三、叙事结构

### 三幕结构（最通用）

| 幕 | 占比 | 关键节点 | 作用 |
|----|------|---------|------|
| 第一幕·建置 | ~25% | 平凡世界 → 激励事件 → 第一扇门 | 交代世界与人物，抛出核心问题 |
| 第二幕·对抗 | ~50% | 上升行动 → 中点（假胜利/假失败）→ 终极危机（最低谷） | 冲突升级，人物受考验 |
| 第三幕·解决 | ~25% | 高潮 → 余波 | 解决核心问题，情绪落地 |

**三个必设节点**：
1. **激励事件**（第①章前后）：让主角无法继续过旧日子的事件
2. **中点**（约一半处）：一次"假性解决"——看似胜利（其实将溃败）或看似失败（其实有转机）
3. **终极危机 + 高潮**（尾声前）：全书最大冲突的正面碰撞，主角靠"成长后的自己"而不是"金手指"获胜

### 起承转合（中式切分，与三幕兼容）

- **起**：开篇，人物与日常
- **承**：事件展开，冲突积累
- **转**：重大转折，局面翻转
- **合**：收束，主题落地

### 高潮设计原则

1. 高潮解决**全书最核心**的那个冲突（不是最后一个临时冲突）
2. 主角的胜利来自**人物弧光的兑现**（内在成长），而非单纯外力
3. 高潮前留**最低谷**（看似必败），情绪落差越大，高潮越爽
4. 高潮后给 1~2 个场景**余波**（交代灵药与众人反应），不要仓促收尾

## 四、写作手法

### show don't tell（展示而非告知）

**不说"他很生气"，而是展示生气的样子。**

- ❌ 告知：他非常愤怒，心想一定要报复。
- ✅ 展示：他攥紧的拳头青筋暴起，杯子里剩下的酒泼了一地。他把烟头碾进桌面，"这件事，没完。"

**转换清单**（把抽象情绪换成可观察的动作/反应）：
愤怒→摔东西/沉默/冷笑/呼吸变重；恐惧→手心出汗/语速变快/逃避眼神；心动→不自觉地靠近/偷看/整理衣领；悲伤→发呆/话少/强撑的笑。

### 感官写作（五感进场景）

每个重要场景至少动用 2~3 种感官：视觉（光影/色彩）、听觉（声音/沉默）、触觉（温度/质感）、嗅觉（气味唤起记忆）、味觉。感官细节让读者"在场"。

### 对话艺术

- **潜台词**：人物说的 ≠ 心里想的。话里有话，比直白更有张力。
  - 例：母亲说"你爸今晚又加班"——潜台词是"你爸在躲我们/又去喝酒了"
- **个性腔调**：每个人物有独特用词、句式、口头禅；反派与主角说话方式绝不相同
- **对话推进冲突**：好的对话是"交锋"，每轮一来一回改变场上局势，而非信息交换
- **删掉寒暄**：删去"你好吗/还好/那就好"式的废话，直接进入有张力的部分

### 伏笔与揭晓

- 伏笔要"回头可见"：读者重读时能发现，当时却不刺眼
- 埋设原则：用**动作/物件/细节**埋，不用旁白说"这很重要"
- 揭晓的爽感 = 读者"原来如此"的恍然大悟，需提前保证线索可回看（见 `03-设定文档/伏笔追踪.md`）

### 反转（意外的必然）

好的反转：**意料之外，情理之中**。
- 反转前必须给足"隐形线索"，回头看不违和
- 反转改变的是**读者对已发生事件的理解**，不是空降新信息
- 用法：反转主角认知、反转反派身份、反转事件归因

### 悬念与章末钩子类型

每一章的结尾必须勾住读者翻页。常用钩子类型：

| 钩子类型 | 用法 | 示例结尾 |
|---------|------|---------|
| 纯悬念 | 悬而未决的问题 | 门缝里伸进一只手 |
| 威胁逼近 | 危险靠近主角而不自知 | 他不知道，此刻整栋楼已停水 |
| 秘密揭示 | 亮出一角，引更多疑问 | "原来她才是……" |
| 情感落点 | 情绪重击（喜/悲/震撼） | 她回头："我等你三年了。" |
| 意外反转 | 局势骤变 | 那张合同上，签的是他自己的名字 |

**勾子要顺接下一章**：第 N 章钩子在第 N+1 章开头至少回应一次。

### 视角 POV 规则（见 `写作风格.md`）

- 全书**锁定视角人物**，不随意"全知跳脑"
- 内心活动只给当前视角人物，旁人只看外部表现
- 视角切换要有明确标记（分节/换章），一章内尽量单一视角

### 节奏与张力

- **长短句穿插**：短句加速（打斗/危机），长句舒展（抒情/铺垫）
- **场景切换**：两场冲突间用短过渡场景缓冲，避免连续高潮疲劳
- **留白**：激烈对话后用一段景物/沉默收尾，让情绪发酵
- **节拍（动作-反应）**：一个动作后接人物的反应（内心/行为），再引下一个动作，形成推拉

## 五、人物弧光

**人物的变化是长篇的脊椎。** 情节再曲折，若人物从头到尾不变，读者会疲劳。

### 弧光类型

| 类型 | 走向 | 适用 |
|------|------|------|
| 正向变化弧光 | 从缺陷/创伤 → 成长/释然（付出代价换得） | 主角最常见 |
| 负向变化弧光 | 从良善 → 堕落/黑化（被环境压垮） | 悲剧主角/反派前传 |
| 平直弧光（固守者） | 立场坚定，用行动**守护**价值并影响他人 | 导师/配角/信仰型主角 |
| 平直弧光（催化者） | 自己不成长，但**催化**他人成长 | 神秘导师、工具型配角 |

### 外在目标 vs 内在需求

```
外在目标：人物嘴上想要的东西（复仇/升职/得到某物）→ 驱动情节
内在需求：人物真正缺失的东西（被爱/原谅自己/安全感）→ 驱动弧光
```

**设计法则**：外在目标即使达成，内在需求未满足仍空虚；故事高潮通常是"外在目标 + 内在需求"同时兑现（或被迫放弃其一换来另一个）。

### 用弧光驱动冲突

- 每卷结束，问：主角**哪里变了**？（认知/能力/关系/价值观）
- 把"变化"写进人物设定表"当前状态"，前后对照就是弧光进度
- 弧光不必直线上升，允许**倒退**（重蹈覆辙）后再爬升，更真实

## 六、场景设计四要素

每一场戏都是一个微型故事，四个要素缺一不可：

```
① 目标：此场景中，视角人物想达成什么？（具体、可观察）
② 冲突：谁/什么阻碍？（没有阻碍就不成场景）
③ 障碍：冲突中的意外或升级
④ 转折：场景结束时，局面/人物关系/认知发生了什么变化
   （事件的意义被重新定义，或角色被迫做出选择）
```

**场景校验**：若场景结束时的状态 == 开始时，说明这个场景是废戏，删或改写。
**作用链**：每个场景的转折应推动下一场景（因果链不断）。

## 七、灵感生成法

创作卡壳时，从这些角度切入，快速获得灵感：

| 方法 | 做法 | 示例 |
|------|------|------|
| **What if（如果…会怎样）** | 把现实前提做一步陌生化假设 | "如果所有人都必须说实话，世界会怎样？" |
| **冲突倒推** | 先定冲突类型，再反推人物与事件 | 定"人物 vs 自我"，反推主角最怕面对什么 |
| **英雄之旅对照** | 把当前章节对照 12 步提问 | "此刻主角该'拒绝召唤'了，他的借口是什么？" |
| **陌生化** | 把熟悉之物写出陌生感 / 把陌生之物写出熟悉感 | 用孩子视角写上班族的一天 |
| **人物互换** | 把两个角色的处境/目标互换 | 若主角是反派的处境，他会怎么做？ |
| **反转前提** | 把设定文档中的常识反过来想 | 世界设定"力量会枯竭"→ 反转"力量越用越多但会失去人性" |
| **代价放大** | 把当前冲突的 stakes 翻一倍/十倍 | 输掉比赛 = 不止丢脸，还丢命 |
| **细节生发** | 从一个物件/一个动作长出一个事件 | 一枚旧表 → 表的主人是谁？ |

**灵感落地的纪律**：
- 灵感必须先与 `03-设定文档/`（世界/人物/红线/伏笔）核对，不产生设定冲突
- 灵感只写进细纲/大纲，不经用户确认不直接写进正文
- 每个灵感至少回答：它给这一章增加了什么冲突或情绪？没有就换一个
