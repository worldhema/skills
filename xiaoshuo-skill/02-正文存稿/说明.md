# 正文存稿目录

> 存放正文章节文件。本目录只放"已定稿"正文。

## 命名约定
- 格式：`第XXX章-标题.md`（章节号三位数递增，如 `第001章-开篇.md`）
- 标题用章节小标题，简洁有钩子

## 章节文件结构
```markdown
# 第XXX章 <标题>

<!-- 正文，约 2000 字，无多余标题行，直接是故事内容 -->

---

<!-- 文件底部可附：本章梗概（novel-track 维护） -->
```

## 流程
1. `novel-write` 生成初稿 → `novel-polish` 定稿后落盘到此目录
2. `novel-track` 在文件底部维护本章梗概
3. `novel-backup` 每章一次 commit

## 草稿
未定稿内容放本目录外（如系统临时目录），或命名时注明 `draft`，避免被 `novel-scan` 误扫。
