# 子技能5 · 内容优化打磨

按审查报告针对性修改，润色对话、增强画面感、调整节奏与章末钩子，产出定稿。

## 输入

- 本章正文初稿
- `novel-review` 产出的审查报告（如有问题）
- `03-设定文档/写作风格.md`

## 输出

打磨后的定稿正文（落盘 `02-正文存稿/第XXX章-标题.md`）。

## 执行步骤

1. 逐条处理审查报告中的问题：OOC → 改回人设；矛盾 → 修正；违禁 → 删除改写；伏笔冲突 → 调整
2. 润色对话：更口语、更有个人腔调、删掉书面腔
3. 增强画面感：补充具体动作、环境细节、感官描写
4. 调整节奏：长句短句穿插，冲突段落提速
5. 强化章末钩子：确保结尾有悬念或情绪落点
6. 通读定稿，确认无残留问题后落盘

## 注意事项

- 打磨不改变剧情事实与人物设定，只优化表达。
- 字数仍保持约 2000 字，不因打磨膨胀或缩水。
- 详细规范见 `04-技能配置/子技能5-内容优化打磨.md`。
