# 创作方法与剧情灵感引擎

调用 `04-技能配置/创作方法论.md` 知识库，为创作提供灵感方案与方法论对照。**只产出建议，不直接生成正文。**

## 输入

用户灵感类提问，例如：
- 「用英雄之旅设计本书主线」
- 「本章可以加什么冲突？」
- 「卡文了，给我一个灵感」
- 「这个反派怎么写更有张力？」
- 「这一章结尾用什么钩子好？」

## 输出

可直接用于创作的具体方案：

1. **方法论对照**：把问题映射到创作方法论（冲突类型 / 英雄之旅 12 步 / 三幕节点 / 钩子类型 / 人物弧光）
2. **灵感方案**：2~3 个具体可选的剧情/冲突/手法建议，每个注明"给这一章增加了什么张力"
3. **衔接校验**：确认建议与 `03-设定文档/`（世界/人物/红线/伏笔）无冲突

## 执行步骤

1. 读取 `04-技能配置/创作方法论.md` 相关章节（冲突 / 英雄之旅 / 手法 / 弧光）
2. 读取 `03-设定文档/`（世界设定、人物设定、伏笔追踪、红线规则）核对约束
3. 针对提问给出方法论对照与灵感方案
4. 输出建议，指明如何落地到 `novel-outline` 细纲或 `novel-write` 正文

## 注意事项

- **不直接生成正文**，产出的是灵感和方案；具体执行仍走 `novel-outline` / `novel-write`。
- 灵感必须与现有设定文档一致，不引入设定冲突。
- 大方向的情节建议（新事件、新反派）须先与用户确认，再写入细纲。
