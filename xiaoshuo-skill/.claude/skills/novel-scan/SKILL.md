# 自动化技能 · 每日存稿备份与合规扫描

每次自动备份 + 扫描敏感词和违规风险。**独立于主流程，只报告不修改。**

## 输入

- 无（用户要求或定时触发）
- 参考 `03-设定文档/合规敏感词清单.md`

## 输出

扫描报告：

1. **合规扫描**：逐章扫描正文，命中敏感词/违规描写的章节与位置清单
2. **备份状态**：`git status` 显示的未提交改动清单
3. **建议**：命中项的处理建议（是否触发 `novel-review` 复审）

## 执行步骤

1. 读取 `合规敏感词清单.md`，整理关键词列表
2. 扫描 `02-正文存稿/` 所有正文文件，匹配敏感词（报告章节号、位置、命中的词）
3. 检查敏感描写（政治、色情、暴力、血腥）风险段落
4. `git status` 检查是否有未提交改动，如有则提示执行 `novel-backup`
5. 输出扫描报告

## 注意事项

- 只报告风险，不自动改写正文；是否处理由用户决定。
- 敏感词清单支持随时增补。
- 详细规范见 `04-技能配置/自动化技能-每日存稿备份与合规扫描.md`。
