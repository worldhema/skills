# 子技能8 · 故事快照

生成一份「当前剧情全局状态」快照文件，让作者（或 AI 自己）一眼看清全书此刻写到哪、每个角色在什么地方做什么，从而校正剧情偏差、推进下一章。

## 输入

- `02-正文存稿/` 最新章节（确定当前进度）
- `03-设定文档/`：人物设定（当前状态）、时间线（当前情节时间线）、伏笔追踪
- `01-大纲细纲/`：全书大纲、分卷细纲（用于进度对照）

## 输出

`06-快照存档/第XXX章-故事快照.md` —— 每次运行生成一份，保留历史便于对比校正。

## 快照文件结构

```markdown
# 故事快照 · 第XXX章

## 一、全局状态
## 二、角色当前状态（表格：角色/位置/时间点/正在做什么/当前目标）
## 三、进行中的剧情线
## 四、当前最相关的未回收伏笔
## 五、剧情进度对照（校正：主线阶段/与大纲偏差/待推进点）
## 六、时间线锚点摘要
## 七、与上一快照的变化
```

## 执行步骤

1. **确定当前进度** — 读取 `02-正文存稿/`，找到最新章节号
2. **摘取角色状态** — 读取 `03-设定文档/人物设定.md`，摘取各角色「当前位置 / 当前状态 / 当前目标」
3. **摘取时间锚点** — 读取 `03-设定文档/时间线.md`，取当前情节时间线末行
4. **筛选未回收伏笔** — 读取 `03-设定文档/伏笔追踪.md`，列出未回收项
5. **进度对照** — 读取 `01-大纲细纲/全书大纲.md` + `分卷细纲.md`，定位当前处于全书第几阶段（英雄之旅第几步 / 三幕第几幕）
6. **对比上一快照** — 若 `06-快照存档/` 已有上一份，列出关键变化
7. **落盘** — 写入 `06-快照存档/第XXX章-故事快照.md`

## 注意事项

- 快照只描述**正文已发生的事实**，不得虚构角色未发生的行动。
- 若快照时发现角色状态 / 时间线 / 伏笔与设定文档不一致，这是**校正信号**：如实提示用户修正设定，而不是粉饰掩盖。
- 快照不是 7 步创作循环的步骤，是独立辅助工具；每章定稿后、或想停下来看整体时运行。
- 详细规范见 `04-技能配置/子技能8-故事快照.md`。
