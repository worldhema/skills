# 子技能4 · 合规与一致性审查

检查规则合规、人物 OOC、剧情矛盾，输出结构化审查报告。**只输出意见，不修改正文。**

## 输入

- 本章正文文本（纯文本，无标题行）
- `03-设定文档/`：人物设定、红线规则、伏笔追踪、合规敏感词清单

## 输出

结构化审查报告（写至 `05-版本备份/` 或直接输出给主流程）：

- **结论**：合规 / 不通过
- **问题清单**（逐条）：类型（OOC / 剧情矛盾 / 违禁 / 伏笔冲突 / 红线违反 / 张力不足 / 结构问题）、位置（原文引用）、说明
- **修改建议**：每条问题对应的具体修改方向

## 执行步骤

1. 检查人物对话与行为是否符合其性格设定（对照人物设定）
2. 检查本章剧情是否与前文矛盾（对照前文梗概）
3. 检查平台规则合规性：违禁词、敏感描写（对照合规敏感词清单与红线规则）
4. 检查伏笔使用是否与伏笔追踪表一致
5. **张力审查**（对照 `04-技能配置/创作方法论.md`）：本章冲突是否清晰（欲望+阻碍+代价）、冲突是否升级、读者情绪曲线是否成立
6. **结构审查**：章末钩子是否有效（对照钩子类型）、场景是否有转折（无转折=废戏）、节奏是否张弛有度
7. 输出结构化审查报告

## 注意事项

- **不修改正文**，只输出审查意见；修改由「内容优化打磨」技能执行。
- 详细规范见 `04-技能配置/子技能4-合规与一致性审查.md`。
