# 子技能2 · 单章剧情推演

基于大纲推演本章核心冲突与转折，产出可执行的章节细纲。

## 输入

- `novel-prep` 产出的创作简报
- `01-大纲细纲/全书大纲.md`、`分卷细纲.md` 中本章对应的规划

## 输出

本章细纲，写入 `01-大纲细纲/章节细纲/第XXX章-细纲.md`：

- 本章 3~5 个**核心事件**（按发生顺序）
- 本章**冲突类型**（对照 `04-技能配置/创作方法论.md` 五种冲突之一或复合）
- 核心**冲突**与**转折**点
- 场景 / 地点 / 登场人物
- **章末钩子**（对照 `创作方法论.md` 钩子类型选定）
- **读者情绪目标**（本章想带给读者的感受：紧张/心动/愤怒/释然…）
- 涉及的新伏笔（标记待登记 `伏笔追踪.md`）

## 执行步骤

1. 对照全书大纲确认本章在主线中的位置（如对照英雄之旅/三幕节点）
2. 读 `04-技能配置/创作方法论.md`，确定本章**冲突类型**（人物vs人物/自我/社会/自然/命运）与冲突三要素（欲望+阻碍+代价）
3. 基于创作简报设计事件序列（3~5 个），冲突逐级升级
4. 设计关键转折与读者情绪曲线
5. 选定**章末钩子类型**（悬念/威胁逼近/秘密揭示/情感落点/意外反转）
6. 写入章节细纲文件

## 注意事项

- 细纲不得偏离全书大纲的主线方向，不凭空引入超出大纲规格的重大事件。
- 冲突与钩子设计参考 `04-技能配置/创作方法论.md`；大方向新情节先与用户确认。
- 详细规范见 `04-技能配置/子技能2-单章剧情推演.md`。
