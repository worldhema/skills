# 子技能1 · 资料整理与前文梳理

自动整理前文剧情、人物状态、未回收伏笔，为主技能提供创作起点。

## 输入

- 待创作章节号（如「第 6 章」）

## 输出

结构化「创作简报」，包含：

1. **前文梗概**：最近 2~3 章发生了什么，剧情推进到哪
2. **人物当前状态清单**：主要人物此刻在哪、情绪状态、正执行什么目标
3. **当前时间锚点**：本章发生的时间点/季节/关键时间约定（来自 `时间线.md`），正文时间不得越界
4. **未回收伏笔清单**：所有 `伏笔追踪.md` 中标记「未回收」的伏笔（含 ID、埋设章节、计划回收章）
5. **本章衔接要点**：上一章结尾的钩子/悬念，本章需承接什么

## 执行步骤

1. 读取 `02-正文存稿/` 最近几章正文，提取剧情要点
2. 读取 `03-设定文档/人物设定.md`，提取当前状态字段
3. 读取 `03-设定文档/时间线.md`，摘取当前情节时间线最后一行的时间锚点与时间规则
4. 读取 `03-设定文档/伏笔追踪.md`，列出未回收伏笔
5. 汇总为简报，输出给主流程

## 注意事项

- 只整理事实，不推断、不规划剧情（那是 `novel-outline` 的事）。
- 详细规范见 `04-技能配置/子技能1-资料整理与前文梳理.md`。
