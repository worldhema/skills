# 主技能 · 平台小说章节全流程创作

统筹调用所有子技能，完成从资料到正文的完整章节流程。**本技能只做调度，不直接生成正文。**

## 输入

- 待创作章节号（如「第 5 章」）
- 用户提供的创作方向 / 本章想要的情节（如有）

## 输出

- 本章正文落盘到 `02-正文存稿/第XXX章-标题.md`
- `03-设定文档/` 追踪文档更新完成
- 一次 git commit

## 执行步骤

创作每一章**必须按顺序执行 7 步**，不可跳步、不可合并：

1. **资料整理** → 调用 `novel-prep`，获取前文状态、人物当前状态、未回收伏笔的创作简报
2. **剧情推演** → 调用 `novel-outline`，规划本章 3~5 个核心事件与章末钩子，产出章节细纲
3. **正文生成** → 调用 `novel-write`，按细纲生成约 2000 字初稿（去 AI 味）
4. **合规审查** → 调用 `novel-review`，检查 OOC / 剧情矛盾 / 平台规则合规，得审查报告
5. **内容打磨** → 调用 `novel-polish`，按审查报告针对性修改，润色对话与画面感、优化钩子
6. **故事线更新** → 调用 `novel-track`，更新人物状态表、伏笔追踪表、章节梗概
7. **自动备份** → 调用 `novel-backup`，git commit（`feat(chapter): 第XXX章-标题`）

## 注意事项

- 创作前先与用户确认本章方向（何时调用：用户意图不明确时，先讨论再动笔）。
- 每章开始前**必须**重读 `03-设定文档/`（红线规则 / 人物设定 / 伏笔追踪）。
- 详细规范见 `04-技能配置/主技能-平台小说章节全流程创作.md`。
