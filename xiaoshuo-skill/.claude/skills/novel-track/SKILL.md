# 子技能6 · 故事线与人物线更新

自动更新世界观文档和伏笔追踪，确保设定文档始终反映正文现状。

## 输入

- 本章定稿正文
- `03-设定文档/`：人物设定、伏笔追踪、写作风格等
- `01-大纲细纲/分卷细纲.md`

## 输出

更新后的：

1. `03-设定文档/伏笔追踪.md` — 新埋设伏笔登记，已回收伏笔标记「已回收」
2. `03-设定文档/人物设定.md` — 主要人物「当前状态」字段更新
3. `03-设定文档/时间线.md` — 当前情节时间线追加本章时间锚点（时间/关键事件/人物状态变化）
4. `01-大纲细纲/分卷细纲.md` — 标注本章进度（已写至第几章）
5. 本章梗概（可在章节文件头部或汇总索引中追加）

## 执行步骤

1. 通读本章正文，提取剧情事实变化
2. 扫描新出现的伏笔 → 在伏笔追踪表新增行（分配伏笔ID）
3. 扫描被回收的伏笔 → 状态改为「已回收」，标注回收章节
4. 更新各人物当前状态字段
5. 在 `时间线.md` 当前情节时间线追加本章一行（时间/关键事件/人物状态变化）；若正文与时间线冲突，先修正正文或登记异常再落盘
6. 更新分卷细纲进度

## 注意事项

- 只记录正文中已发生的事实，不推断未发生的情节。
- 伏笔ID 采用统一编号（如 `F-001`），全局唯一。
- 时间线是锚定铁律：正文出现的日期/季节/年龄/称谓必须与 `时间线.md` 一致，发现冲突须修正。
- 详细规范见 `04-技能配置/子技能6-故事线与人物线更新.md`。
